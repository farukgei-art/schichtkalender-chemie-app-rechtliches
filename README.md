# Schichtkalender Chemie – Rechtliches

Datenschutzerklärung, Impressum und Support-Kontakt für die App Schichtkalender Chemie.

Diese Seiten werden **nicht von Hand** geändert. Sie entstehen aus `src/legal/legalContent.json` der App:

```bash
node scripts/build-legal-pages.mjs
```

So sagen App und Webseite immer dasselbe.
